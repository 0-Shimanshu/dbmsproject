# Project Summary

## Stack (Current)

- Backend: FastAPI + SQLAlchemy ORM
- Database: PostgreSQL (`psycopg2`)
- Auth: JWT (`python-jose`) and role-based authorization
- Frontend: Vanilla JavaScript SPA

## Current Active Folders

- `client/` frontend pages, styles, and feature modules
- `fastapi_server/` active backend code
- `sql/schema.sql` PostgreSQL schema used by the FastAPI backend

## Removed / Deprecated

- Legacy Node/Express backend (`server/`) has been removed.
- Unused migration placeholder files in `migrator/` were removed.

## Status

Repository is aligned around the Python/FastAPI + PostgreSQL architecture.
